We use Matomo and Vercel Web Analytics to understand website traffic. Vercel Speed Insights is disabled in our project dashboard; this control also covers its installed integration. You can opt out of these integrations below. Analytics is allowed by default until you opt out. Read our [Privacy policy](/privacy) for details about how we handle information.

<AnalyticsPreferenceControl />

Your choice applies to this website in this browser. We save it in local storage without a scheduled expiry, until you change it or clear site data. Use the **Analytics opt-out** link in the footer to return here. Saving a choice reloads the page so it takes effect for all three integrations. If preferences cannot be read, these analytics integrations stay off.

Opting out stops future collection by these integrations; it does not delete data already collected. It does not control hosting/security logs, external websites, or YouTube videos and thumbnails. Those services can still receive connection information when you use them. Matomo may also store an opt-out preference cookie when stopping an already loaded tracker.
